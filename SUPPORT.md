# Support

CommandCore is community-maintained free software.

## Where to ask

Use GitHub issues for:

- reproducible bugs;
- installation defects;
- documentation errors;
- narrowly scoped feature requests.

Include the CommandCore version, operating system, agent implementation, relevant
non-sensitive logs, expected behavior, and actual behavior.

## What not to post

Do not post credentials, access tokens, private keys, device identity files,
private URLs, databases, backups, or security exploit details.

Security issues follow SECURITY.md.

## Support level

The project does not provide a guaranteed response time or operational SLA.
Maintainers may close requests that cannot be reproduced, are outside the current
support matrix, or depend on an unsupported client/platform combination.

Community help, documentation improvements, and reproducible test cases are
welcome.
