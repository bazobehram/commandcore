# Maintainers

Current repository maintainer:

- @bazobehram

Maintainers review pull requests, protect security boundaries, coordinate
releases, and handle private vulnerability reports.

Maintainer access is not granted solely for commit volume. The governance policy
in GOVERNANCE.md describes the expected path: sustained high-quality
contributions, reliable review, security awareness, and constructive project
participation.

Security-sensitive changes may require explicit review from a maintainer even
when ordinary CI and review requirements have passed.
