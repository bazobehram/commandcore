# Code of conduct

CommandCore contributors are expected to keep project spaces professional,
welcoming, and technically constructive.

## Expected behavior

- Discuss ideas and code rather than attacking people.
- Give actionable review feedback and assume good faith unless evidence shows
  otherwise.
- Respect different levels of experience and ask for clarification without
  ridicule.
- Disclose conflicts of interest that materially affect a technical or governance
  decision.
- Keep private security reports and private user data confidential.
- Do not use project spaces for harassment, threats, discrimination, spam, or
  targeted disruption.

## Scope

This policy applies to issues, pull requests, reviews, discussions, project chat,
release coordination, and other spaces where someone is representing the
CommandCore project.

## Enforcement

Report serious conduct problems privately to a project maintainer. Maintainers may
edit or remove content, limit participation, close threads, or block contributors
when necessary to protect the project and its participants.

Enforcement decisions should be proportionate to the behavior, documented
privately when sensitive, and avoid exposing reporters unnecessarily.
