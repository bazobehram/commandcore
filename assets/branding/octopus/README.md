# CommandCore octopus brand assets

These are the static light, dark, transparent and Android maskable octopus icons used by the CommandCore Workspace identity. The authoritative vector geometry lives under `apps/workspace-angular/public/brand/`. The deterministic PNG export script is `apps/workspace-angular/scripts/brand_icons.py`; building the Angular app regenerates the installable app icons. The animated SVG variants respond to actual application state; static app icons do not animate in ChatGPT or installed PWA launchers.
