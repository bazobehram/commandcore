# CommandCore branding

The supplied PNG artwork is preserved without redrawing or recoloring:

- `../../apps/web/commandcore-icon.png`: square symbol for client icons and favicons.
- `../../apps/web/commandcore-wordmark.png`: original horizontal wordmark for light backgrounds.
- `commandcore-stacked.png`: stacked wordmark for other brand placements.

The dark web headers pair the original transparent symbol with light text and
a blue Core accent. The supplied navy wordmark stays available without adding
a white background to the control panel. The existing WebP URL remains available for older clients.
