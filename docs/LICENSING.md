# Licensing

CommandCore is free software under **GNU AGPL-3.0-or-later**.

The AGPL was selected because CommandCore is a network-accessible control plane.
The project should remain inspectable and modifiable by its users even when a
modified version is offered as a hosted network service.

## Repository code

Unless a file states otherwise, source code and documentation in this repository
are distributed under AGPL-3.0-or-later.

The canonical license text is in LICENSE.

## Contributions

Contributions are accepted under the same AGPL-3.0-or-later terms. Contributors
must certify origin using the Developer Certificate of Origin sign-off described
in CONTRIBUTING.md.

## Dependencies and third-party material

Dependencies remain under their upstream licenses. Their inclusion does not
relicense them under the AGPL. See THIRD_PARTY_NOTICES.md,
docs/DEPENDENCY_LICENSES.md, and the committed SBOM material.

Before distributing release binaries or container images, maintainers must
re-run dependency/license audits and verify distribution obligations for the
exact shipped artifacts.
